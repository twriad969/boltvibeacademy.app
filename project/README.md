# Project Title

## Description
This project is a web application that offers a promotional license for n8n, featuring a user-friendly interface and visually appealing components. The application includes a checkout form and highlights the benefits of the offered license.

## Components
- **LicenseOffer**: A component that displays a promotional offer with a styled background, grid lines, and glowing orbs. It includes a title, description, and an icon.
- **FeatureHighlights**: A new component that will feature a background image and highlight the key features of the application.

## Assets
- **Background Image**: The project includes a background image located at `public/bg-feature-highlights.jpg`, which will be used in the `FeatureHighlights` component.

## Setup
To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd project
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

## Usage
Once the server is running, you can access the application in your web browser at `http://localhost:3000`. The main page will display the checkout form along with the promotional offer and feature highlights.
